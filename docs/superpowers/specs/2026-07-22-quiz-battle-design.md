# 실시간 퀴즈쇼 앱 "퀴즈 배틀" — 설계 문서

작성일: 2026-07-22

## 1. 개요

관리자가 출제하고 다수의 참가자가 폰으로 실시간 응답하는 Kahoot 스타일 퀴즈쇼 앱.
문제마다 20초 긴박한 카운트다운 연출, 정답+속도 기반 점수, 실시간 순위 갱신.
여러 개의 퀴즈쇼를 미리 만들어 두고 상황에 맞게 골라 진행할 수 있음.
디자인 테마: **스케치북 + 크레파스 손그림 메모** 감성.

## 2. 기술 구성

- **호스팅**: GitHub Pages (정적 호스팅, 무료)
- **실시간 백엔드**: Firebase Realtime Database (신규 프로젝트, 드라큘라 게임과 분리)
- **구성 파일**
  - `index.html` — 참가자 화면 (코드 입력 → 닉네임 → 문제 풀이)
  - `admin.html` — 관리자 화면 (퀴즈쇼 제작 + 진행 조종석, 대형 스크린 겸용)
- 별도 프레임워크 없이 바닐라 JS + Firebase SDK (기존 프로젝트 패턴 유지)

## 3. 역할·화면 구조

### 관리자 (admin.html)
- **암호 입력**으로 접속 보호 (간단한 비밀번호 게이트)
- 퀴즈쇼 목록: 만들기 / 수정 / 삭제
- 퀴즈쇼 편집기: 문제 추가·수정·삭제·순서변경
- 진행 조종석: 방 열기 → "다음 문제 / 정답 공개 / 종료" 버튼으로 진행
- **대형 스크린 겸용**: 관리자 화면을 강의장 스크린에 띄워 문제·타이머·순위를 함께 표시 (별도 호스트 화면 없음)

### 참가자 (index.html)
- 6자리 방 코드 + 닉네임 입력 → 로그인/가입 없음
- 대기실 → 문제 표시 → 20초 안에 응답 → 결과·내 순위 확인

## 4. 게임 흐름

```
방 열기 → 대기실(참가자 모임) → [관리자 시작]
 → 문제 표시 + 20초 타이머 → 참가자 응답
 → 시간 종료 또는 전원 응답 → 정답 공개 + 이번 문제 순위
 → [다음 문제] … 반복 → 최종 순위 발표 🏆
```

## 5. 20초 긴박 연출

- 원형 **크레파스 질감 프로그레스 링**이 20→0으로 감소 (초록→노랑→빨강)
- 마지막 5초: 숫자 확대 + 붉은 펄스 + (선택) 비프음
- 남은 시간이 짧아질수록 화면 긴장감 상승

## 6. 점수·순위

- **정답 기본 100점 + 속도 보너스**: 예) 정답 시 `100 + (속도 보너스, 남은시간 비례)`
- **x2 문제**: 관리자가 특정 문제를 "2배 점수"로 지정 가능 → 해당 문제 획득 점수 전체 2배
- 오답 / 미응답: 0점
- 문제마다 즉시 순위 갱신
- 종료 시 종합 리더보드 + TOP3 시상대

## 7. 문제 형식

- **4지선다**: 색깔 버튼 탭, 자동 채점
- **O/X**: 큰 O/X 버튼, 자동 채점
- **단답형**: 텍스트 입력, **정확히 일치할 때만 정답** (오타·띄어쓰기 틀리면 오답)
  - 관리자가 **인정 답안을 여러 개 등록** 가능 (예: "이순신", "이순신 장군")
- (선택) 문제별 이미지 첨부

## 8. 데이터 구조 (Firebase Realtime Database)

```
quizzes/
  {quizId}/
    title
    questions/
      {qId}/ { type, text, choices[], answer(s), image? }

rooms/
  {코드}/
    quizId
    state          // waiting | question | reveal | ended
    currentQ       // 현재 문제 인덱스
    startedAt      // 현재 문제 타이머 시작 시각(서버 기준)
    players/
      {playerId}/ { nick, score }
    answers/
      {qIndex}/{playerId}/ { choice, time }
```

- 방(`rooms`)은 세션 종료 후 정리, 퀴즈쇼 원본(`quizzes`)은 보존

## 9. 디자인 테마 — 다크 칠판 + 파스텔 크레용/분필

선정 톤: **다크 칠판 (C안)** — 대형 스크린 가독성·집중도가 가장 높음.

- 어두운 칠판(딥 그린/차콜) 배경, 살짝 분필 질감
- 파스텔 크레용/분필 컬러 팔레트 (밝은 코랄·블루·옐로·그린)
- 손글씨 느낌 폰트 (Gaegu 등, 한글 지원 필수)
- 크레용으로 그린 듯 살짝 삐뚤빼뚤한 테두리·도형
- 20초 타이머 링·버튼도 크레용 질감, 마지막 5초 붉게 확대되는 연출

## 10. 범위 밖 (YAGNI)

- 계정 로그인/회원가입 없음
- 별도 호스트 대형스크린 페이지 없음 (관리자 화면 겸용)
- 단답형 유사도(퍼지) 채점 없음 — 정확 일치만
- 문제당 제한시간은 **20초 고정** (문제별 시간 조절 없음)
